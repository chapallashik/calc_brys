Подключение

не настроено

Панель сама записывает цены в файл prices.json вашего репозитория. Нужен токен доступа — вводится один раз и хранится только в этом браузере.

Репозиторий в формате логин/название
Ветка обычно main
Токен доступа Fine-grained token с правом Contents: Read and write

Где взять токен: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. В Repository access выбрать свой репозиторий, в Permissions → Repository permissions → Contents поставить Read and write. Срок действия лучше поставить максимальный, иначе публикация перестанет работать после истечения.

Доступ

пароль к этой панели

Калькулятор открыт всем без пароля — пароль закрывает только эту панель. Он не хранится в открытом виде: в репозиторий уходит лишь его хеш. Новый пароль начинает действовать на всех устройствах.

Новый пароль не короче 6 символов
Повторите пароль

Пароль отсекает случайных посетителей. Реальную защиту даёт токен: без него изменить цены нельзя, даже зная пароль. Поэтому храните токен аккуратнее пароля.
